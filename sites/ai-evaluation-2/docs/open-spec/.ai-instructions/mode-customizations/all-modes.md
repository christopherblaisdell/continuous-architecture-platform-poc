# All Modes - Universal Standards Reference

This file serves as a reference for standards that apply to ALL modes in the Roo AI system. Every mode MUST load and apply these standards without exception.

## Mandatory Universal Standards

All modes MUST load the following from the `universal/` directory:

1. **[`corporate-standards.md`](../universal/corporate-standards.md)**
   - No emojis policy
   - Professional communication requirements
   - Audit trail requirements
   - Error handling standards

2. **[`effort-estimation.md`](../universal/effort-estimation.md)**
   - Sprint-based estimation only
   - No dollar values ever
   - Complexity-based sizing
   - Risk buffer calculations

3. **[`markdown-formatting.md`](../universal/markdown-formatting.md)**
   - Header formatting rules
   - Document structure standards
   - Code block requirements
   - File naming conventions

4. **[`file-organization.md`](../universal/file-organization.md)**
   - Directory structure standards
   - Naming conventions
   - Date prefix requirements
   - Version control practices

5. **[`security-uptime-basic.md`](../universal/security-uptime-basic.md)**
   - Basic security awareness
   - Uptime considerations
   - Data classification
   - Incident escalation

## Core Behaviors (All Modes)

### Communication Style
- Technical and direct
- No conversational openers
- No questions at end
- Evidence-based claims only

### Documentation
- Proper markdown formatting
- Consistent file organization
- ISO 8601 date formats
- Clear section structure

### Estimation
- Sprints for effort
- Complexity ratings
- Risk assessments
- Never monetary values

### Security Awareness
- Consider data classification
- Document security decisions
- Highlight risks
- Escalate concerns

## Mode-Specific Overlays

While these universal standards apply to all modes, each mode may have:
- Additional specialized standards
- Mode-specific methodologies
- Unique workflows
- Specialized templates

Mode-specific customizations build upon but never override universal standards.

## Enforcement

These universal standards are:
- **Mandatory** - No exceptions
- **Auditable** - Will be reviewed
- **Career-impacting** - Violations have consequences
- **Continuously updated** - Check for changes
